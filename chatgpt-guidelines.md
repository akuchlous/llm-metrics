# ChatGPT guidelines — writing Claude prompts

**Before every new Claude prompt:** read this file and [the authoritative checklist](prompts/PROMPT_WRITING_CONTRACT.md) from GitHub. Do not rely on chat memory.

The checklist defines required sources, scope, safeguards, design questions, tests, reports, history updates, and review gates. Apply it to every numbered micro-step.

**Responsibility split:** ChatGPT authors/reviews prompts; Claude implements one step and stops. GitHub is the source of truth. A new Claude session must be able to execute the prompt without access to our chat.
