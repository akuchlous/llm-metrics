• One model, one workload, one region. Results describe gpt-6-luna answering one kind of chat request from Google Cloud us-central1. Other prompts, output lengths, regions or networks can behave differently.
  • No rankings. We measure a single provider today, so nothing here says which model or provider is fastest.
  • Client-observed time. Our TTFT includes the network path and connection setup from our region. It is not OpenAI's internal processing time.
  • No quality grading. We measure speed, reliability, tokens and cost, not whether the answers are good.
  • Small samples. Early datasets have few requests. Percentiles from them are unstable, and the metric page flags this.
  • Observed reliability, not uptime. The success rate is what our requests experienced, not a statement about the provider's availability.
  • Estimated cost. Costs are calculated from reported token counts and list prices, not from invoices. The cost of a failed request is unknown and is counted as unknown, not as zero.
