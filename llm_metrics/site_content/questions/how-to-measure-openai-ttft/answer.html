Time to first token (TTFT) is how long an API caller waits from sending a request until the first piece of generated text arrives. We measure it on the client: a monotonic timer starts just before the streaming request is made and stops when the first output-text event from OpenAI's streaming Responses API reaches our code.

That makes our TTFT the time to the first text chunk, not the time to the first network byte and not a token-exact count. It includes connecting to the API, queueing and processing the prompt, because a real caller waits for all of those.

Every measurement uses the same fixed, versioned prompt and settings, from the same cloud region, and is recorded whether it succeeds or fails. We report percentiles over successful requests only and count failures separately, so a failed request never appears as a fast one.
