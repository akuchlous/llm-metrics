Single requests vary, so latency is reported as percentiles over many requests. The median (p50) shows a typical request; the 95th percentile (p95) shows how slow the slow ones are. Averages hide slow outliers and are easy to distort.

Failed requests are counted separately and never included as fast latency values. Every published figure should state how many successful requests it is based on, the time window, the model, the prompt and settings, and where the requests were sent from.
