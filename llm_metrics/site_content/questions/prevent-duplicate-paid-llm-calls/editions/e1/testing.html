The controls are covered by offline tests that use a simulated storage service and provider, so they cost nothing. In one test, eight runs for the same slot start at the same instant: exactly one provider call, one claim and one record result. In another, a delivery arrives every minute from 30 minutes before the window to 30 minutes after it: exactly 96 provider calls are made.

These tests show that the code behaves as designed against a simulated store. They do not prove how the real cloud services behave in every failure case.
