The collector can only run one fixed measurement: request profile openai.gpt-6-luna.v1, workload interactive-chat-v1, from Google Cloud. Nothing about the target can be chosen by the caller.

Its activation window comes from the job's configuration and must start on a quarter-hour and last exactly 24 hours, which allows exactly 96 slots. Missing, shorter, longer or misaligned windows are refused. The scheduler's identity may only start the job; it cannot change the window. A run that starts more than 7 minutes after its slot began is refused, and the window's end and the late limit are checked again immediately before the request.

Before claiming a slot, the job also checks that it can create and read objects in its results bucket and that overwrites are refused, so it does not spend money on a request it could not record.
