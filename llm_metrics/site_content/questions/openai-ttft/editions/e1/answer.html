We have not published a validated measurement of OpenAI time to first token yet, so this page shows no number. When a validated dataset is published, the measured median and 95th percentile TTFT appear below, with the sample size, time window and limitations alongside them.

The measurement covers one model, OpenAI gpt-6-luna, with one fixed prompt and settings, sent from one Google Cloud region. It does not describe other models, prompts or locations, and it is not a ranking.
