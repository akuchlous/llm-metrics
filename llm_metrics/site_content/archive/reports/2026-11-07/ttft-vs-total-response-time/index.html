Question

What is the difference between TTFT and total response time?

Archived edition, published 7 November 2026 (UTC). Read the current answer.

Answer

Time to first token (TTFT) is how long you wait until an LLM starts answering. Total response time is how long you wait until the whole answer has arrived. Both start when the request is sent. TTFT stops at the first piece of generated text; total response time stops at the last.

The gap between them is the generation time: how long the model takes to produce the rest of the answer after the first token.

Why they differ

A streaming request goes through two broad phases. First, the request travels to the provider, waits for capacity and the model reads the prompt. That phase ends when the first output text is sent back, which is what TTFT captures.

Second, the model generates the answer one token at a time. Each new token takes roughly the same amount of work, so a long answer keeps the connection open much longer than a short one. Total response time includes both phases.

This is why the two numbers can move independently. A busy service or a very long prompt mostly raises TTFT. A request for a long answer mostly raises total response time.

Which one matters

  • Chat and other streaming interfaces: TTFT matters most, because people see text appear and can start reading while the rest is generated.
  • Batch jobs, tool calls and structured output: total response time matters most, because nothing can be used until the full answer has arrived and been parsed.
  • Without streaming: the caller sees nothing until the end, so the experienced wait is the total response time even though the model still produced a first token earlier.

Limitations

Both numbers are measured from the caller's side, so they include network time and depend on where the caller is. Comparing them across providers is only fair with the same prompt, settings, answer length and location. A TTFT or total response time figure without the prompt size and output length behind it says little.
