Question

How does output token count affect LLM response time?

Archived edition, published 7 November 2026 (UTC). Read the current answer.

Answer

For most LLM APIs, output token count is the biggest single driver of total response time. Models generate text one token at a time, so an answer twice as long takes roughly twice as long to generate. Time to first token (TTFT) is affected much less, because it ends as soon as the first token is produced.

Why longer answers take longer

A model reads the whole prompt in one pass, which can be done largely in parallel. Generating the answer is different: each new token depends on the tokens before it, so they are produced in sequence. The speed of that sequence is often reported as output tokens per second.

A useful approximation is: total response time ≈ TTFT + (output tokens ÷ output tokens per second). The approximation is rough, because the generation rate is not constant and varies with load, but it explains why answer length matters so much.

How to control it

  • Ask for less: clear instructions about length and format usually shorten answers more than any setting.
  • Set an output limit: a maximum output token setting caps the worst case. A capped answer can be cut off mid-sentence, so check whether the response says it stopped because of the limit.
  • Stream the answer: streaming does not make generation faster, but people can start reading after the first token instead of waiting for the last.
  • Watch reasoning tokens: some models generate internal reasoning tokens before the visible answer. These take generation time and are usually billed, even though they are not shown.

Effect on cost

Output tokens are usually billed per token, and often at a higher price than input tokens. Longer answers therefore cost more as well as taking longer. The authoritative token counts are the ones the provider reports in its usage data, not an estimate made from the text.

Limitations

The relationship between output length and time is an approximation. Generation speed differs by model, provider, time of day and request settings, and it can change without notice. Any comparison should hold the prompt, model, settings and answer length fixed.
